GITHUB PAGES SETUP

1. Create a public GitHub repository named: ishu-birthday
2. Upload index.html, style.css and script.js to the repository root.
3. Create folders named photos and music.
4. Upload your existing photos into photos/ and birthday.mp3 into music/.
5. Go to Settings > Pages. Choose Deploy from a branch, branch main, folder /(root), then Save.
6. Your site will be at: https://YOUR-USERNAME.github.io/ishu-birthday/

Important: GitHub Pages hosts static HTML/CSS/JS, so app.py and requirements.txt are not needed.
